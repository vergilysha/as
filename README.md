# Memory — стартовий пакет (частина 1)

Заготовка гри «Memory» для практикуму «Memory, частина 1: відкриваємо картки».

У пакеті **немає готового дизайну і готових картинок**: стилі — нейтральний сірий каркас, а замість зображень — заглушки з цифрами. Тему, кольори, шрифт і 8 зображень ваша команда обирає сама (кроки «Дизайн-паспорт» і «Оформлення» в практикумі).

## Як використати (капітан команди)

1. Створіть проєкт Vite (крок 0 практикуму):

   ```
   npm create vite@latest memory -- --template react
   cd memory
   npm install
   ```

2. Скопіюйте з цього пакета у свій проєкт:
   - `index.html` — замініть наявний;
   - папку `src` — замініть повністю;
   - папку `public/img` — покладіть у свою `public`;
   - файл `CREDITS.md` — покладіть у корінь проєкту.

3. Запустіть проєкт:

   ```
   npm run dev
   ```

На екрані має з’явитися сітка 4×4 із сірих карток зі знаком «?». Клік поки нічого не робить — цього ви навчите картки в практикумі.

## Що всередині

```
index.html
CREDITS.md          — таблиця джерел зображень (заповните у кроці «Оформлення»)
public/img/cards/   — 8 заглушок: card-1.svg … card-8.svg
src/
  main.jsx
  index.css         — каркас стилів: сітка, закрита / відкрита / відгадана картка
  App.jsx
  data/data.js      — 16 карток: id та url
  components/
    Grid.jsx        — сітка карток
    Card.jsx        — одна картка
```
